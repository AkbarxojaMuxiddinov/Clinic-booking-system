# 🏥 Shifo Klinikasi — Booking Bot & Web System

Интерактивная система онлайн-записи для медицинской клиники, объединяющая веб-сайт на Django, Telegram-бота и ИИ-ассистента Gemini AI.

## 🚀 Основные возможности

* **Веб-сайт клиники:** Полный веб-интерфейс для ознакомления с услугами и записи на прием.
* **Автоматическое сохранение:** Данные записей и клиентов синхронизируются в единой базе данных SQLite.
* **Telegram Bot & Gemini AI:** Умный бот для консультации пациентов и управления записями.
* **Админ-панель:** Удобное управление услугами, клиентами и бронированиями через Django Admin.

## 🛠 Технологический стек

* **Backend:** Python 3.14, Django 6.1
* **Database:** SQLite3
* **Bot & AI:** python-telegram-bot, Google Gemini API
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
